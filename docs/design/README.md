# 화면 시안

시각 참고용이다. 문구나 동작이 [`../spec.md`](../spec.md) 와 다르면 spec 이 우선한다.
브라우저에서 파일을 바로 열면 된다 (외부 글꼴만 Google Fonts 에서 받음).

| 파일 | 화면 | 메모 |
| --- | --- | --- |
| `screens.html` 1번 | 로그인 입력란 규칙 패널 | 입력란을 누르고 입력하면 줄 상태가 바뀐다. 카카오·네이버는 실제 db 규칙, 세 번째는 조합·금지 규칙을 보여주려는 가상 예시. spec §4 |
| `screens.html` 2번 | 팝업 7가지 상태 | 밝은/어두운 테마 전환 가능. 규칙 있음, 상위 도메인 매칭, 규칙 없음, 불러오는 중, 조회 실패, 웹사이트 아님, 개발 빌드 설정. spec §5 |
| `screens.html` 3번 | 숨긴 사이트 설정 페이지 | 숨긴 사이트 목록과 "다시 표시". spec §4.5 |
| `logo.svg` | 로고 원본 | 한 가지 색 벡터(`currentColor`), 원 r32 + 둥근 끝 사선. 익스텐션 아이콘은 이 로고에 흰 원형 배경을 깐 `public/icons/icon.svg`. spec §1.4 |
